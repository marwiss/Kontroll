# opencde-client

Python client for buildingSMART OpenCDE servers: Foundation API 1.0 (OAuth2
authorization code with PKCE), BCF API 3.0 and Documents API 1.0.

The library is written for the [Kontroll OpenCDE server](../README.md) and is
intended to be contributed to IfcOpenShell's `bcf` package later. It is
therefore licensed under LGPL-3.0-or-later, unlike the server (AGPL-3.0).

Status: scaffold. The API arrives in stage 7 of the plan.
